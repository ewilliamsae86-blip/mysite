**Hachiroku.fun — Personal Website**

**About This Project**

Hachiroku.fun is a personal website I am developing as a hands-on project to improve my web development skills. The site will feature information about my hobbies and interests, including my Toyota AE86, Japanese language studies, and banjo playing.

Rather than using a website builder, I chose to build the website using HTML and CSS to gain practical experience with web development.

**Technologies Used**

HTML5

CSS3

**Development Process**

I am developing this website through a combination of independent learning, experimentation, and AI assistance. I use AI as an additional learning resource while developing my understanding of web development and working through technical challenges.

This project is helping me gain practical experience with website structure, styling, and maintaining a personal website.

**Future Development**

I plan to continue improving the website as I develop my technical skills and as time allows, adding content about my hobbies and interests while refining its design and functionality.
